WhatsApp Warmer

The WhatsApp Warmer is a per-number "warm-up" system. It gradually ramps up how much a number sends and paces every send, so a number builds a natural sending history instead of going from zero to bulk overnight. The goal is to lower the risk of bans and protect each number's quality rating. This is a v1.2 feature.

What it is

Every connected number gets its own warm-up profile. Rather than treating all your numbers the same, the Warmer lets each number ramp at its own pace and stay inside its own safe daily limit. A fresh number starts small and slowly earns a higher daily budget over the following days, exactly the way a real person's usage would grow.

The Warmer is not just a planning tool — its limits are actually enforced on the real bulk-sending paths. Campaigns, broadcasts, and scheduled sends all obey the number's daily budget, the minimum gap between sends, and the active-hours window, and they apply spintax variation automatically.

Tip: For the Unofficial API, warming is primarily about ban avoidance — pacing and varying messages so the number looks like a normal human account. For the official channels (WhatsApp Cloud API and Twilio), warming acts as volume pacing to protect the quality rating, since Meta enforces its own messaging tiers on its side.

Why and when to use it

New WhatsApp numbers that immediately blast large volumes are the classic trigger for a ban or a quality-rating drop. The Warmer smooths that out.

  • Bringing a fresh number online. Start the number on a small daily budget and let it ramp up over several days before you point big campaigns at it.
  • Protecting an established number during big campaigns. Keep an already-trusted number safely paced so a one-off large send does not spike its volume and hurt its standing.
  • Running steady, human-like activity. The gap floor and active-hours window stop a number from firing hundreds of messages back-to-back at 3 a.m., which is a strong spam signal.

How it works

Each number's warm-up profile is made up of a few simple controls. Together they shape both how much the number may send and how it sends.

ControlWhat it does
Ramping daily budgetThe maximum number of messages the number may send in a day. It starts low and increases day by day, so the number builds volume gradually instead of all at once.
Minimum gap between sendsA floor on the time between two messages from the same number, so sends are spaced out rather than fired in a burst.
Active-hours windowThe number only sends during the hours you set (for example normal business hours), mimicking when a real person would be messaging.
Spintax message variationEach message is worded slightly differently using spintax, so the same campaign does not send an identical string to everyone — a common bulk-spam fingerprint.
Health scoreA simple indicator of how well the number is being warmed and paced, so you can see at a glance which numbers are in good shape.

When a campaign, broadcast, or scheduled send runs, WaDesk checks each outbound message against the sending number's profile: it confirms the number is still under its daily budget, that enough time has passed since the last send to satisfy the gap floor, and that the current time is inside the active-hours window. It then applies spintax to the message body before sending and records the send so the budget and gap stay accurate. This applies across all three engines.

How to set up a warm-up profile

  1. Open Warmer from the menu (URL /warmer).
  2. Pick the number you want to warm and open its profile.
  3. Set the ramping daily budget — the starting daily cap and how it should grow day by day.
  4. Set the minimum gap between sends and the active-hours window the number should send within.
  5. Add your spintax variations so messages are reworded automatically.
  6. Save. From now on, campaigns, broadcasts, and scheduled sends from that number automatically respect these limits — there is nothing extra to switch on per campaign.
  7. Check the health score periodically and adjust the ramp if you want the number to grow faster or slower.

Where to find it

The Warmer lives at /warmer. Open it from the WaDesk menu to see your connected numbers and their warm-up profiles and health scores in one place.

Plan availability

Access to the WhatsApp Warmer depends on your plan. If you do not see it in the menu, your current plan may not include it — check your plan details or contact the platform owner.
