Trello Integration

Connect a Trello board to WaDesk so that activity on your board can trigger a WhatsApp action — for example, when a member is assigned to a card, notify them on WhatsApp.

How it works. Trello calls a WaDesk webhook whenever something happens on the board you registered; WaDesk reads the event and runs the matching action.

What it does

  • Reacts to Trello board events — e.g. a member added to a card (assignment) — and turns them into a WhatsApp action through WaDesk.
  • Keeps your project board and your WhatsApp outreach in sync without manual copy-paste.

How to set it up

  1. In WaDesk, open Integrations and choose Trello.
  2. Provide your Trello API credentials/token as prompted on the page.
  3. Register a board webhook pointing at the WaDesk Trello endpoint shown on the integration page, for the board you want to watch.
  4. Trigger an event on the board (e.g. assign a member to a card) to confirm the action fires.

Good to know

  • Trello sends a verification request (HEAD/POST) when a webhook is created; WaDesk's endpoint accepts it.
  • Availability of the integration can depend on your plan.
  • For pushing WaDesk events into other tools, see Webhooks; for HubSpot/store sync, see E-commerce & CRM.
